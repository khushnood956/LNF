# Lost and Found System

A personal full-stack **Lost & Found Management System** built to practice real-world application structure, clean repository organization, and frontend–backend separation. The project is organized with a clear focus on scalability, learning, and maintainability.

---

## 📂 Repository Structure

```
Lost-And-Found/
│
├── Backend/        # Spring Boot backend (APIs, DB, business logic)
├── Frontend/       # Frontend UI (HTML / CSS / JS / React)
├── docs/           # Documentation, notes, and references
│
├── .gitattributes
├── .gitignore
├── README.md       # Main project documentation
```

This structure is intentional:
- **Backend** and **Frontend** are fully isolated
- Easy to deploy or work on either side independently
- Clean and professional GitHub layout

---

## 🔧 Backend (Spring Boot)

The backend is developed using **Spring Boot** and focuses on:
- RESTful APIs for Lost & Found items
- MySQL database integration
- CRUD operations (Create, Read, Update, Delete)
- Clean project structure following best practices

**Tech Stack:**
- Java
- Spring Boot
- MySQL
- Maven

📁 Location: `Backend/`

---

## 🎨 Frontend

The frontend provides a responsive and user-friendly interface for interacting with the system.

Features include:
- Item listing and form handling
- Basic DOM event handling
- Responsive layout
- Organized UI structure

**Tech Stack:**
- HTML
- CSS
- JavaScript
- (React setup included where applicable)

📁 Location: `Frontend/`
